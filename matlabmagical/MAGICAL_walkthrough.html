MAGICAL MATLAB Method Walkthrough

This document provides a detailed walkthrough of the MAGICAL (Modeling And Generative Inference of Cis-regulatory Architecture and Logic) method, based on the provided MATLAB source code. MAGICAL integrates single-cell RNA-seq and ATAC-seq data to infer gene regulatory circuits, including TF-peak binding and peak-gene looping interactions.

Overall Workflow

The main entry point is the MAGICAL.m script. It orchestrates the entire process, which can be broken down into four main stages:

  1. Data Loading: All input data (scRNA-seq, scATAC-seq, motif scans, genomic annotations) is loaded into memory.
  2. Candidate Circuit Construction: The vast search space is narrowed down by selecting a plausible set of candidate TFs, peaks, and genes based on expression, accessibility, and prior biological knowledge (e.g., TAD boundaries, motif scans).
  3. Model Initialization: Priors and initial values for the model's latent variables are estimated from the data. This is a critical step that grounds the model in biological reality.
  4. MAGICAL Estimation (Gibbs Sampling): A Bayesian inference scheme (Gibbs sampler) is used to iteratively sample from the posterior distribution of the model parameters, ultimately yielding probabilities for TF-peak binding and peak-gene looping.

% Main script: MAGICAL.m

% 1. Load Data
fprintf('loading all input data ...

% ... code to load scRNA, scATAC, motifs, etc. ...

');
% ... code to save results ...

1. Priors and Model Initialization

The script MAGICAL_initialization.m is responsible for setting the priors. Priors are the model's initial beliefs about the parameters before observing the detailed single-cell data. MAGICAL uses data-driven priors derived from linear models.

Prior on TF Activity (T)

The activity of a transcription factor is assumed to be related to its own RNA expression. The prior for each TF's activity is a Normal distribution, with the mean and variance derived directly from its log2-transformed RNA counts across the different biological samples. 


% From: MAGICAL_initialization.m

% TF activity prior: TF RNA expression
T_sample_mean = Candidate_TF_log2Count;
T_sample_var = var(Candidate_TF_log2Count, 0, 2);

% T_A_prior and T_R_prior are then initialized by sampling from
% N(T_sample_mean, T_sample_var) for each cell.

Prior on TF-Peak Binding (B)

The prior belief about whether a TF (m) binds to a peak (p) is determined by the relationship between the TF's expression and the peak's accessibility. A linear model (fitlm) is fit for each potential TF-peak pair (defined by motif scans):

PeakAccessibility_p ~ β₀ + β₁ * TF_Expression_m

The estimated coefficient (β₁) becomes the prior mean for the binding weight. The p-value of this coefficient is transformed and used as the prior probability of binding. This intuitively means that if a TF's expression is strongly correlated with a peak's accessibility across samples, the model starts with a stronger belief that the TF binds that peak. 


% From: MAGICAL_initialization.m

% B_prior holds the regression weights (β₁)
% B_prob holds the prior probabilities (1 - p_value)
[xx,yy] = find(Candidate_TF_Peak_Binding > 0); % Find potential bindings
for i=1:length(xx)
    mdl = fitlm(Candidate_TF_log2Count(yy(i),:)', Candidate_Peak_log2Count(xx(i),:)');
    B_prior(xx(i), yy(i)) = table2array(mdl.Coefficients(2,1)); % Get β₁
    B_prob(xx(i), yy(i)) = 1 - table2array(mdl.Coefficients(2,4)); % Get 1 - p_value
end
B_mean = B_prior;

% The variance for the weight is estimated from the variance of all binding
% weights associated with that TF.
for m=1:M
    B_var(m) = 1 * var(B_prior(Candidate_TF_Peak_Binding(:,m)>0, m));
end

Prior on Peak-Gene Looping (L)

The logic is identical to the TF-Peak binding prior. To establish the initial belief about a peak (p) looping to a gene (g), a linear model is fit:

GeneExpression_g ~ γ₀ + γ₁ * PeakAccessibility_p

The coefficient (γ₁) becomes the prior mean for the looping weight, and its p-value informs the prior probability of a loop existing. 


% From: MAGICAL_initialization.m

[xx,yy] = find(Candidate_Peak_Gene_looping > 0);
for i=1:length(xx)
    mdl = fitlm(Candidate_Peak_log2Count(xx(i),:)', Candidate_Gene_log2Count(yy(i),:)');
    ATAC_RNA_weight_1 = table2array(mdl.Coefficients(2,1));
    ATAC_RNA_probability_1 = 1 - table2array(mdl.Coefficients(2,4));
    L_prior(xx(i),yy(i)) = ATAC_RNA_weight_1;
    L_prob(xx(i),yy(i)) = ATAC_RNA_probability_1;
end
L_mean = L_prior;
L_var = var(L_prior(L_prior~=0));

2. MAGICAL Estimation: The Gibbs Sampler

The core of the method is in MAGICAL_estimation.m. It uses a Gibbs sampler to iteratively refine the estimates of the latent variables T (TF Activity), B (TF-Peak Binding), and L (Peak-Gene Looping). The sampler works by drawing samples for each variable from its conditional posterior distribution, holding the other variables fixed.

The model has two main equations:

  1. A_s = B × T_s + ε_A   (scATAC-seq model)
  2. R_s = Lᵁ × (B × T_s) + ε_R   (scRNA-seq model)

Where A_s is peak accessibility, R_s is gene expression, T_s is TF activity, B is the binding matrix, L is the looping matrix, and ε represents noise.


% From: MAGICAL_estimation.m

for i=1:iteration_num
    
    %********** scATAC-seq fitting and variable sampling ****************
          
    %Step 1: TF activity sampling
    [T_A, T_R, T_sample] = TF_activity_T_sampling(...);
    
    %Step 2: TF-peak binding weight sampling
    B = TF_peak_binding_B_sampling(...);
    
    %Step 3: TF-peak binding state update
    [B_state, B] = TF_peak_binary_binding_B_state_sampling(...);
    
    %Step 4: ATAC fitting residue variance control    
    sigma_A_noise = 1/gamrnd(...);
       
    %********** scRNA-seq fitting and variable sampling *****************      
    
    %Step 5: Peak-Gene looping weight sampling
    L = Peak_gene_looping_L_samping(...);
    
    %Step 6: Peak-Gene looping state update
    [L_state, L] = Peak_gene_binary_looping_L_state_samping(...);
    
    %Step 7: RNA fitting residue variance control
    sigma_R_noise = 1/gamrnd(...);
        
    %********** sample summary *****************
    % Keep track of how often a binding/looping event is sampled as "on"
    B_state_frq = B_state_frq + B_state;
    L_state_frq = L_state_frq + L_state;
end

Step 1: Sampling TF Activity (T)

TF_activity_T_sampling.m: Samples TF activity for each TF m. Because the priors are Normal and the likelihood is Normal, the conditional posterior is also Normal. The mean and variance of this posterior are calculated based on the current binding weights (B), the observed peak accessibility data (A_sample), and the TF activity prior.

Steps 2 & 3: Sampling TF-Peak Binding (B and B_state)

This is a two-part process for each potential TF-peak interaction.

  1. Sampling the binary state (TF_peak_binary_binding_B_state_sampling.m): This is the crucial decision step. The model calculates the posterior probability of binding (P(B_state=1 | Data, T, L)) by comparing the likelihood of the data if the TF is bound versus if it's not. This calculation incorporates both the likelihood (how well the data is explained) and the prior probability (B_prob). A random number is compared to this posterior probability to decide whether to sample the state as 1 (bound) or 0 (not bound).
  2. Sampling the weight (TF_peak_binding_B_sampling.m): If the state is sampled as 1, a binding weight is then sampled from its conditional posterior (another Normal distribution). If the state is 0, the weight is fixed at 0.

% From: TF_peak_binary_binding_B_state_sampling.m

% Calculate posterior probability of binding (P1)
% This compares the likelihood of the current weight (if state=1) vs a weight of 0 (if state=0)
post_b1 = exp(-(B(p,m)*1-mean_B)^2/(2*vairance_B)) * (B_prob(p,m)+0.25) + 1e-6;
post_b0 = exp(-(B(p,m)*0-mean_B)^2/(2*vairance_B)) * (1-B_prob(p,m)+0.25) + 1e-6;

P1 = post_b1 / (post_b1 + post_b0);
threshold_c = rand;

if P1 >= threshold_c
    % Sample state as 1 (or keep it 1)
else
    % Sample state as 0 (or keep it 0)
    B(p,m) = 0;
    B_state(p,m) = 0;
end

Steps 5 & 6: Sampling Peak-Gene Looping (L and L_state)

This process mirrors the sampling for B and B_state, but it operates on the scRNA-seq model.

  1. Sampling the binary state (Peak_gene_binary_looping_L_state_samping.m): The model calculates the posterior probability of a loop existing (P(L_state=1 | Data, T, B)) by comparing the likelihood of the observed gene expression (R_sample) with and without the loop. The prior probability (L_prob) is included. A state of 1 or 0 is then sampled based on this probability.
  2. Sampling the weight (Peak_gene_looping_L_samping.m): If the state is 1, a looping weight is sampled from its Normal conditional posterior. Otherwise, the weight is 0.

Final Output

After many iterations, the algorithm computes the final probabilities for TF-peak binding and peak-gene looping by calculating the frequency with which each `B_state` or `L_state` was sampled as 1. For instance, if a specific TF-peak binding state was 1 in 800 out of 1000 iterations, its final binding probability is 0.8. 


% From: MAGICAL_estimation.m

Candidate_TF_Peak_Binding_prob = B_state_frq / iteration_num;
Candidate_Peak_Gene_Looping_prob = L_state_frq / iteration_num;
